SIRUKUN 1.1 — PAKET XAMPP DENGAN AES-256-GCM
===========================================

PERSYARATAN
- XAMPP PHP 8.2+; Apache dan MySQL/MariaDB aktif.
- Ekstensi: openssl, pdo_mysql, pdo_sqlite, mbstring, fileinfo,
  ctype, tokenizer, dom, xml, xmlwriter, gd, zip.
- mod_rewrite aktif; AllowOverride All untuk htdocs.
- Sediakan sedikitnya 256 MiB memori PHP untuk pemakaian awal.
- Paket RAR menyertakan vendor; tidak memerlukan Composer/Node.js.
  Unduhan source GitHub memerlukan composer install --no-dev.

PEMASANGAN BARU
1. Ekstrak sehingga app, public, vendor, artisan langsung berada di:
   C:\xampp\htdocs\sirukun\
2. Start Apache dan MySQL.
3. Buka http://localhost/sirukun/public/install.php melalui localhost.
4. Isi koneksi database baru/kosong, identitas RW/RT, dan akun Administrator.
5. Installer membuat database terenkripsi dan dua kunci acak pada .env.
   Installer terkunci setelah pemasangan. Tidak ada kata sandi bawaan.
6. Simpan .env di tempat aman terpisah dari data/backup. Jangan mengubah
   DATA_ENCRYPTION_KEY atau APP_KEY setelah aplikasi dipasang.
7. Buka http://localhost/sirukun/public/ dan masuk dengan akun baru.
8. Lengkapi wilayah, hunian, KK, warga, lalu akun pengurus dan Warga.

PEMASANGAN LAMA (VERSI 1.0)
JANGAN menimpa .env dan storage berisi dokumen dengan folder kosong paket.
JANGAN menjalankan installer browser ulang.
Ikuti PANDUAN_AES_GCM.md, termasuk penghentian Apache/scheduler,
pembuatan kunci data, migrasi terverifikasi ke database baru, konversi
berkas, perubahan .env, penghapusan salinan plaintext lama, serta uji login.
Source baru akan menolak koneksi web yang masih memakai penyimpanan lama.

ENKRIPSI DAN BATAS
Seluruh nilai tabel logis (termasuk ID, tanggal, status, dan audit),
dokumen, backup, sesi, cache, dan log aplikasi dienkripsi AES-256-GCM.
MySQL menyimpan vault ciphertext. Skema layanan 25 tabel diproses di RAM
menggunakan SQLite :memory:. Jangan mengedit vault melalui phpMyAdmin.
Batas snapshot JSON 16 MiB; dokumen disimpan terpisah. Akses database
diproses bergiliran. Versi ini untuk pemasangan RT/RW kecil; belum dilakukan
benchmark beban. Jangan menjalankan worker persisten/Octane.
Kunci dan kredensial pada .env wajib dilindungi; metadata ukuran/path masih
terlihat. Data layar dan unduhan laporan untuk pengguna berwenang didekripsi.
Enkripsi temporary upload PHP, swap, serta backup OS memerlukan konfigurasi
volume/server. Rincian lengkap ada pada PANDUAN_AES_GCM.md.

BACKUP DAN PENJADWAL
Menu Administrator menyediakan backup .sirukun terenkripsi.
Salin juga storage/app/private yang terenkripsi dan simpan kunci terpisah.
Restore hanya ke database baru/kosong menggunakan kunci asal; baca panduan.
Jalankan scheduler.bat melalui Windows Task Scheduler setiap menit:
pengingat setiap lima menit dan backup harian pukul 01.00.

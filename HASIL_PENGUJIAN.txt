SIRUKUN 1.1 — HASIL PENGUJIAN AES-256-GCM
========================================
Tanggal: 23 Oktober 2026
Runtime: PHP 8.3.6, SQLite in-memory, MariaDB 10.11.14 pada Linux.

44 pengujian PHPUnit lulus, 225 assertions.
- 33 pengujian aplikasi: login, empat peran, isolasi wilayah,
  persetujuan RT/RW, lima jenis surat, empat mutasi, PDF/QR, laporan Excel,
  berkas privat, menu, notifikasi, dan log terenkripsi.
- 11 pengujian kriptografi/penyimpanan: roundtrip Unicode/binary/kosong,
  nonce acak, penolakan kunci salah, perubahan IV/tag/ciphertext/AAD,
  tidak ada fallback plaintext, persistence reopen, rollback/nested
  transaction, batas ukuran, manifest/chunk hilang atau tertukar,
  dokumen stream/copy/move, metadata, cache, lock, serta sesi GCM.

33 pengujian alur aplikasi diulang melalui EncryptedConnection:
LULUS, 175 assertions.

Uji integrasi HTTP + MariaDB nyata, database khusus pengujian:
- Installer browser baru, pembuatan dua kunci acak, dan penguncian installer.
- Login berbasis sesi, penolakan POST tanpa CSRF, halaman Administrator.
- MySQL hanya memiliki sirukun_vault; payload tidak memuat nilai uji
  nama/email/kelurahan sebagai teks biasa.
- Sesi server memiliki authentication tag GCM 16 byte.
- Backup .sirukun tetap ciphertext saat diunduh.
- Restore terautentikasi ke database baru/kosong berhasil.
- Migrasi database lama ke database baru, verifikasi hash/jumlah/relasi,
  pembukaan ulang ciphertext, dan enkripsi berkas lama berhasil.
- NIK/nama/alamat/relasi hasil migrasi tetap dapat dibaca oleh aplikasi.
- Dua penulis paralel pada MariaDB tidak kehilangan pembaruan.
- Pembukaan vault dengan kunci salah atau payload dimanipulasi ditolak.

Tidak ada database/kunci konfigurasi runtime/dokumen/log pengujian yang
masuk ke repositori atau paket pemasangan. Kunci di phpunit.xml hanya fixture.

Batas:
- Belum diuji langsung pada Windows/XAMPP.
- Tidak dilakukan benchmark beban atau penetration test menyeluruh.
- Snapshot maksimal 16 MiB, seluruh data SQL diproses di RAM,
  dan koneksi database diserialkan selama pemrosesan permintaan.
- Pengujian enkripsi aplikasi tidak menjamin enkripsi temporary upload PHP,
  swap, log web server, atau salinan backup pada perangkat pengguna.
Lihat PANDUAN_AES_GCM.md sebelum memperbarui instalasi yang sudah berisi data.

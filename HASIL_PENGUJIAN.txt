SIRUKUN 1.0 - HASIL PENGUJIAN
============================
Tanggal: 15 Oktober 2026
Runtime pengujian: PHP 8.3.6, SQLite, MariaDB 10.11.14.
Target paket: PHP 8.2+, MySQL/MariaDB, XAMPP Apache.

32 pengujian aplikasi lulus dengan 172 assertions pada SQLite dan MariaDB.
Termasuk:
- Login/logout, otorisasi empat peran, isolasi data RT/RW.
- Pembatasan akses permohonan/berkas Warga.
- Persetujuan hanya oleh Ketua RT/RW, tanpa melewati tahap RT.
- Pending dan revisi mengembalikan alur persetujuan dengan riwayat terjaga.
- PDF nyata, QR/token, pengarsipan, pencabutan, nomor berurutan tanpa duplikasi.
- Seluruh lima jenis surat dapat diterbitkan.
- Keempat jenis mutasi, NIK bayi kosong, penerapan satu kali.
- Penggantian kepala keluarga, termasuk saat pindah/meninggal.
- Tamu dan penghuni sewa beserta identitas, periode, serta kontak darurat.
- Notifikasi tidak digandakan.
- Ekspor laporan PDF dan Excel .xlsx.
- Pengelolaan akun, pembatasan menu, dan validasi halaman/formulir.

Uji integrasi HTTP pada instalasi baru dengan MariaDB:
- Installer membuat database/tabel, data dasar, dan akun Administrator.
- Installer terkunci setelah pemasangan.
- Login dengan cookie/sesi dan kata sandi nyata.
- POST tanpa token CSRF ditolak dengan HTTP 419.
- Dashboard, tabel, formulir, serta menu Administrator dapat dimuat.
- Backup SQL berhasil dibuat dan diunduh.
- SQL backup dipulihkan ke database kosong terpisah.
- Ekspor Excel menghasilkan berkas .xlsx.

Dependensi dikunci melalui composer.lock untuk PHP 8.2.12.
Audit dependensi Composer saat penyusunan tidak menemukan advisory keamanan.
Paket menyertakan vendor, source, migrasi, dan pengujian; tidak menyertakan
database pengujian, kata sandi Administrator, sesi, atau .env terpasang.

Batas verifikasi:
Paket belum diuji langsung pada Windows/XAMPP. Tidak dilakukan pengujian
beban atau pengujian penetrasi menyeluruh. Uji coba lokal dengan data contoh
sebelum memasukkan data warga sesuai prosedur operasional pengurus.
